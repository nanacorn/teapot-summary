# 티팟 AI 요약 → 장기기억 (복사해서 붙여 넣기)

크랙용 "요약 메모리 편집 & AI 자동 요약" 스크립트의 티팟판. 템퍼몽키 유저스크립트.
채팅을 읽어 **한국어, 공백 포함 1만 자 이하**로 압축하고 팝업에 보여 준다. 사용자가 복사해서 티팟 장기기억 칸(연필 버튼)에 붙여 넣는다. 티팟 화면에는 아무것도 자동으로 쓰지 않는다.

## 설치
1. 템퍼몽키 → 새 스크립트 → 기본 내용을 지우고 `teapot-summary.user.js` 전체를 붙여 넣고 저장.
2. 티팟 채팅방(`teapotchat.com/chat/...`)을 새로고침하면 오른쪽 위 톱니 옆에 `✨ AI 요약` 버튼이 생긴다.

## 쓰는 법
1. `✨ AI 요약`을 눌러 팝업을 연다.
2. API 종류와 키를 넣는다(이 브라우저의 localStorage에만 저장).
   - `Vertex (Express 키)`(기본): Vertex AI 콘솔의 API 키 한 줄. 서비스 계정 JSON 키는 쓸 수 없다.
   - `AI Studio`: aistudio.google.com/apikey 키.
3. 모델, 요약할 턴 수(0 = 전체, 기본), 글자 수 한도(기본 10,000)를 정한다.
4. 이미 장기기억이 있으면 티팟에서 그 내용을 복사해 `기존 장기기억` 칸에 붙여 넣는다. 새 대화와 합쳐 한도 안으로 다시 압축한다. 비워 두면 대화만 요약한다.
5. `요약 생성` → 결과를 확인·수정 → `복사` → 티팟 장기기억의 연필 버튼으로 편집창을 열어 붙여 넣고 저장.

## 글자 수 한도
- 모델에게 한도의 85%(1만 자면 8,500자)를 목표로 준다. 모델은 글자 수를 정확히 못 세기 때문이다.
- 결과가 한도를 넘으면 자동으로 최대 2번 줄여 달라고 다시 요청한다. 그래도 넘으면 경고를 띄우고, 복사 때 한 번 더 확인한다.
- 결과 칸을 직접 고쳐도 글자 수가 실시간으로 표시된다.

## 확인한 것 / 못 한 것
- 확인: 버튼 표시, 팝업, 대화 읽기, 요청 본문(기존 장기기억 포함), 한도 초과 → 자동 줄이기 흐름(가짜 응답으로).
- 못 함: 실제 Vertex Express 키 호출, 100턴 넘는 채팅에서의 읽기, 1만 자 압축의 실제 품질.
- 이 방식은 티팟 화면에 쓰지 않으므로, 티팟 화면이 바뀌어도 읽기(DOM) 부분만 영향을 받는다.

## 설치 주소 · 자동 업데이트
- 설치: 크롬에서 아래 주소를 열고 템퍼몽키의 `설치`를 누른다.
  https://raw.githubusercontent.com/nanacorn/teapot-summary/main/teapot-summary.user.js
- 업데이트: 템퍼몽키가 하루에 한 번 확인해서 받는다. 바로 받으려면 대시보드에서 `업데이트 확인`.
- 코드를 고칠 때는 `@version`을 올려야 업데이트로 인식된다.
